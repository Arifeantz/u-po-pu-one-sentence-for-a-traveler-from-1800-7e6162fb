One sentence that explains the modern internet to a time traveler from 1800, built only from things a person of that year already knows — a road, a post office, a library. The program prints the sentence to `/output/entry.txt`: a road from your door to every library and post office on earth, where your letter finds a friend across the sea in a blink and any page you ask for is in your hands before your tea cools.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
cat output/entry.txt
```
